전투 에이전트 입력

전투 정책(CombatPolicy)이 한 시점에서 보는 것 전부입니다. 관측은 토큰 묶음이고, 순서 없는 Transformer 가 읽은 뒤 행동과 타깃을 고릅니다. 수치 뒤의 /50 같은 표시는 모델에 넣을 때 나누는 값입니다.

행동이 되는 토큰내 상태적어댑터가 붙이는 토큰기타

① 관측 = 토큰 묶음

전역 1개 · 항상 맨 앞

  • 이번 전투(조우) 종류 임베딩
  • HP 비율 HP/최대 HP, 방어도 /50, 에너지 /10
  • 뽑을·버린·소멸 더미 장수 /20
  • 턴을 끝내면 잃을 HP 예측 4칸 꺼짐 · 0

행동 토큰 토큰 1+i = 행동 i · 최대 32

평소

  • 손패 카드 (손패 순서 그대로): 카드 종류 임베딩, 강화 여부, 지금 비용 /5, 인챈트 종류·수치
  • 턴 종료
  • 포션 칸 9개 (하나라도 있을 때): 포션 종류 임베딩, 있는지

카드 고르기 화면

  • 후보 카드 (카드 종류·강화·비용, 10장까지 공개)
  • 고르지 않기

카드 더미 카드 한 장 = 토큰 하나

  • 뽑을 더미 · 버린 더미 · 소멸 더미 (정렬됨, 뽑을 더미 순서는 모름)
  • 고르기 화면일 때의 손패 (낼 수 없는 손패)
  • 각각 카드 종류, 강화, 지금 비용 /5, 인챈트

나 유물 · 버프

  • 유물: 종류 임베딩, 카운터 /20
  • 버프·디버프 (힘, 취약 …): 종류 임베딩, 수치 /20

적 적 슬롯마다 · 주인 = 슬롯 번호

  • 적 종류 임베딩, HP /50, HP 비율, 방어도 /50 (죽은 적도 HP 0 으로 남음)
  • 이번 턴 의도: 공격·방어·강화·약화·알 수 없음 + 수치 /30
  • 다음 턴 의도 (시뮬레이터가 알려 줄 때)
  • 적 버프·디버프: 종류, 수치 /20

자원 · 오브 어댑터가 맨 뒤에

  • 골드 /300, 최대 에너지 /10
  • 오브 칸·별·오스티·오브마다 하나 (다른 직업용, 아이언클래드는 없음)

카드 고르기 화면 종류 v6 새로

고르기 화면이 열려 있을 때 하나: 손패 강화 · 손패 소멸 · 소멸 후 뽑기 · 뽑을 더미 → 손패 … (27 가지) 임베딩

RUN 토큰 전투만 학습에서는 없음

런 학습 때만: 평가기가 만든 런 요약(덱·유물·상태·맵, 다음 노드가 휴식인지 등) 벡터 하나.

+주인 나 / 적 슬롯 1~8
+id 임베딩, 종류마다 다른 표
카드 · 버프 · 의도 · 적 · 유물 · 포션 · 조우 · 오브 · 자원 · 고르기
+수치 18칸 → 선형층
HP, 방어도, 에너지, 더미 장수, 강화, 비용, 인챈트 수치, 적 HP·비율·방어도, 의도 수치, 크기(버프·카운터), 턴 종료 예측 4칸
+인챈트 임베딩 (카드 토큰만)

카드·유물·적 임베딩은 덱·유물 인코더(평가기)와 같은 표를 씁니다. 카드 효과 문구는 들어가지 않고, 카드마다 벡터를 학습으로 익힙니다.

③ 읽고 고르기

순서 없는 Transformer3층 · 128칸 · 머리 4개 · 위치 인코딩 없음
모든 토큰이 서로를 봅니다 (적 의도 ↔ 손패 ↔ 버프).
행동 고르기행동 토큰마다 [그 토큰 ; 전역 토큰] → 작은 MLP → 점수. 지금 낼 수 없는 행동은 지우고 softmax.
타깃 고르기적이 필요한 카드·포션이면: 고른 행동 토큰(질의) · 적 토큰(열쇠) → 적마다 점수 → softmax.

학습: 같은 전투를 같은 시드로 8번 싸워 점수(이기면 1 + 남은 HP 비율, 지면 적에게 준 피해 비율)로 순위를 매기는 GRPO.

들어가지 않는 것

  • 적이 몇 번 때리는지: 의도 수치는 한 번 피해뿐입니다. 공격 12 × 3 인지 알 수 없습니다.
  • 내 HP 의 실제 값과 최대 HP: HP 비율만 들어갑니다. 80 중 40 과 40 중 20 이 같아 보입니다.
  • 몇 번째 턴인지, 이번 턴에 이미 낸 카드 목록 (버린 더미로만 짐작).
  • 카드 효과 문구: 카드는 id 로만 구분합니다. 처음 보는 카드는 무엇을 하는지 모릅니다.
  • 고르기 화면을 연 카드: 화면 종류는 들어가지만(v6) 어떤 카드가 열었는지는 없습니다.
  • 뽑을 더미의 순서: 일부러 정렬해서 숨깁니다 (실제 게임에서도 모름).
  • 턴 종료 예측: 칸은 있지만 계산이 느려서 꺼 두었습니다 (늘 0).
  • 후보가 10장을 넘는 고르기 화면: 11번째부터는 카드 정체가 비어 있습니다.
  • 적의 최대 HP·다음 행동 패턴 규칙: 적 종류 임베딩으로 학습해 익혀야 합니다.
